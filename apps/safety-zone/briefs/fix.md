# Build 수정 지침 — Review 1차 결과 반영

## 수정 허용 범위
- `apps/safety-zone/` 안의 앱 코드만 (index.html, css/, js/, assets/)
- 수정 금지: `spec.md`, `review.md`, `briefs/*`, 폴더 밖 모든 파일. git 명령 금지.

## 고칠 문제 (상세·재현 방법은 `apps/safety-zone/review.md` 참고)
1. **M1 [중간]** 브라우저 메뉴(Ctrl+P)로 인쇄하면 빈 페이지 — `css/print.css:23-25`, `js/utils/export.js:47`
   - 앱 버튼으로 인쇄할 때만 body에 인쇄 모드 클래스를 붙이고 `afterprint`에서 제거. 클래스가 없을 때 직접 인쇄하면 현재 화면이 그대로(탭 바 등 UI만 숨긴 채) 인쇄되게 한다.
2. **L1** 전담 조직 '해당 없음' 자동 표시 후 50인 이상으로 재진단해도 복원 안 됨 — `js/views/check.js:76-84`
   - 앱이 자동으로 바꾼 경우(표시 플래그 등)에만 50인 이상 재진단 시 '미착수'로 되돌린다. 사용자가 직접 바꾼 값은 건드리지 않는다.
3. **L2** 터치 대상 44px 미만: 홈 글 속 링크, TBM 칩 삭제 버튼(44×40) — `home.js:22·52`, `log.js:96`
4. **L3** 일부 키만 든 백업 가져오기 시 나머지 데이터·면책 동의가 초기화됨 — `store.js:255-267`
   - 백업에 있는 키만 덮어쓰고 없는 키는 유지(또는 확인 대화로 선택). 면책 동의는 유지.
5. **L4** 내보내기 종료일 기본값이 오늘이라 미래 날짜 기록 누락 — `more.js:105` → 기본값을 기록 중 가장 늦은 날짜(또는 비워 두면 제한 없음)로.
6. **L5** 체크리스트 CSV "다음 점검 예정일" 칸의 '해당 없음' 문구 혼동 — `more.js:28` → 빈칸 또는 '반기 점검 대상 아님'.
7. **L6** 위험성평가 제목·날짜 수정 시 부제와 `document.title` 즉시 갱신 — `risk.js:242-245, 295`
8. **L7** 면책 모달이 Esc 연타로 닫힐 수 있음 — `main.js:84` → 동의 버튼 외에는 닫히지 않게(`cancel` 이벤트 preventDefault 등).

## 확인
- 수정한 JS는 `node --check`로 문법 확인. 브라우저 재검증은 Review 담당이 한다.
