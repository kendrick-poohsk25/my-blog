# Build 수정 지침 2 — Review 2차 검증의 낮음 등급 N1·N2

## 수정 허용 범위
- `apps/safety-zone/` 안의 앱 코드만 (index.html, css/, js/)
- 수정 금지: `spec.md`, `review.md`, `briefs/*`, `preview.png`, 폴더 밖 모든 파일. git 명령 금지.

## 고칠 문제 (상세는 `apps/safety-zone/review.md`의 "2차 검증" 섹션)
1. **N1** 반기 점검 항목에 점검일이 없으면 체크리스트 CSV "다음 점검 예정일" 칸에 `'-`가 찍힘
   - 원인: 값 `-`가 수식 주입 방지 규칙(`=`, `+`, `-`, `@` 시작 칸에 `'` 붙임)에 걸림
   - 수정: 그 칸에 `-` 대신 '점검일 미입력'을 넣는다. 인쇄 문서 등 같은 값을 쓰는 다른 곳도 일관되게. 수식 주입 방지 규칙 자체는 약화하지 않는다.
2. **N2-a** 앱이 자동으로 '해당 없음'(`autoNa`)으로 표시한 전담 조직 항목을 사용자가 직접 바꿔도 자동 메모 문구가 남음 — `js/views/duties.js:109` 부근
   - 수정: 사용자가 상태를 바꿔 `autoNa`가 해제될 때, 메모가 자동 문구와 정확히 같으면 비운다. 사용자가 고친 메모는 유지.
3. **N2-b** 위험성평가가 없을 때 TBM 화면의 '위험성평가 작성하기' 링크 높이가 40px → 44px 이상으로 (기존 `.touch-link` 등 재사용).

## 확인
- 수정한 JS는 `node --check`. 가능하면 N1은 node로 CSV 생성 결과를 확인. 브라우저 검증은 Review 담당.
