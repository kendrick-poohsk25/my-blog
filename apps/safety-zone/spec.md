## 1. 한 줄 소개와 대상 사용자

**한 줄 소개**: 작은 사업장이 산업안전보건법·중대재해처벌법 의무를 빠뜨리지 않도록, 자가진단부터 위험성평가·일일 점검 기록까지 브라우저 하나로 챙기는 안전관리 도우미.

**주 대상**: 상시 근로자 **5~49인** 중소사업장의 대표(경영책임자)와 안전관리 담당자(겸직 포함)

| 근거 | 설명 |
|---|---|
| 새로 적용된 집단 | 중대재해처벌법이 2024-01-27부터 50인 미만(5인 이상) 사업장까지 확대 적용됨. 준비가 가장 덜 된 층 |
| 전담 인력 없음 | 안전관리자 선임 의무가 없는 규모가 많아, 대표나 사무직이 겸직하는 경우가 흔함 |
| 비용 부담 | 컨설팅·유료 솔루션 도입이 어려움 → 무료·설치 없는 웹앱이 맞음 |
| 기록 부재 | 사고 후 "의무를 이행했다"는 증빙(문서·기록)이 없는 경우가 많음 → 기록·내보내기가 핵심 가치 |

**함께 지원하는 대상 (사용자 결정)**: **건설 현장** — 자가진단에 공사금액 분기(50억 원 기준 유예 이력), 위험성평가·TBM 점검 항목에 건설 작업(고소작업, 중장비, 개구부 등)도 공통 예시 안에 포함

**보조 대상**: 5인 미만 사업장(중처법 적용 제외지만 산안법은 적용), 50인 이상 사업장의 현장 반장(TBM 기록용)

## 2. 해결할 문제 — 두 법이 사업주에게 요구하는 것

> 표기 원칙: 확실한 내용만 적고, 수치·세부 기준이 불확실한 것은 **(확인 필요)**로 표시. 구현 전 법제처(law.go.kr) 원문으로 재확인한다.

### 2-1. 산업안전보건법 (줄여서 산안법)

**적용 범위**: 원칙적으로 근로자를 쓰는 모든 사업장. 다만 일부 조항은 업종·규모에 따라 적용 제외(시행령 별표 1).

| 의무 | 쉬운 말 | 근거 |
|---|---|---|
| 안전·보건 조치 | 추락·끼임·화재·질식 등 위험을 막는 조치를 해야 함 | 제38조, 제39조 |
| 위험성평가 | 일터의 위험요인을 찾고, 얼마나 위험한지 따져서, 줄이는 대책을 세우고 기록·보존 | 제36조, 고용노동부 고시 「사업장 위험성평가에 관한 지침」 |
| 위험성평가 시기 | 최초평가, 매년 정기평가, 설비·공정 변경 등 시 수시평가 | 위 고시 (최초평가 착수 기한 등 세부 확인 필요) |
| 위험성평가 방법 | 빈도×강도 방식 외에 체크리스트법, 3단계 판단법, 핵심요인 기술법도 인정(2023년 고시 개정) | 위 고시 (확인 필요) |
| 안전보건교육 | 근로자 정기교육, 채용 시 교육, 작업내용 변경 시 교육, 특별교육 | 제29조 (교육 시간 기준은 개정 이력이 있어 확인 필요) |
| 안전보건관리담당자 | 20~49인 일부 업종(제조업, 임업, 하수·폐수, 폐기물, 환경정화 등)은 담당자 1명 이상 선임 | 제19조 (업종 목록 확인 필요) |
| TBM(작업 전 안전점검회의) | **법정 의무는 아니지만** 위험성평가 결과를 근로자에게 공유하는 수단으로 정부가 권장 | 위험성평가 고시에서 언급 (확인 필요) |
| 처벌 | 안전·보건 조치 위반으로 근로자 사망 시 7년 이하 징역 또는 1억 원 이하 벌금 | 제167조 |

### 2-2. 중대재해처벌법 (줄여서 중처법)

**적용 범위**
- 2022-01-27 시행. 상시 근로자 **5인 미만 사업(장)의 사업주는 제외**(제3조).
- 50인 미만(건설업은 공사금액 50억 원 미만)은 유예되었다가 **2024-01-27부터 적용**.

**중대산업재해란** (제2조 제2호) — 다음 중 하나
1. 사망자 1명 이상
2. 같은 사고로 6개월 이상 치료가 필요한 부상자 2명 이상
3. 같은 유해요인으로 급성중독 등 직업성 질병자가 1년 이내 3명 이상

**경영책임자의 핵심 의무** (제4조): 안전보건관리체계 구축·이행, 재해 재발방지 대책, 행정기관 개선·시정명령 이행, 안전보건 관계 법령상 의무 이행에 필요한 관리상 조치

**안전보건관리체계 9개 항목** (시행령 제4조)

| # | 항목 | 쉬운 말 | 주기 |
|---|---|---|---|
| 1 | 안전·보건 목표와 경영방침 | 대표가 "우리 회사 안전 목표"를 정해 문서로 공표 | — |
| 2 | 전담 조직 | 안전·보건 업무를 총괄하는 전담 조직 (일정 규모 이상만 해당, **5~49인은 대부분 비해당** — 기준 확인 필요) | — |
| 3 | 유해·위험요인 확인·개선 절차 | 위험요인을 찾고 고치는 절차를 만들고 점검 (위험성평가로 갈음 가능) | 반기 1회 이상 점검 |
| 4 | 안전·보건 예산 | 필요한 인력·시설·장비 예산을 편성하고 실제로 집행 | — |
| 5 | 책임자 권한·예산 부여 및 평가 | 안전보건관리책임자 등에게 권한·예산을 주고 업무를 평가 | 반기 1회 이상 평가 |
| 6 | 전문인력 배치 | 산안법상 안전관리자·보건관리자·안전보건관리담당자·산업보건의 배치 | — |
| 7 | 종사자 의견 청취 | 일하는 사람의 의견을 듣고 개선하는 절차 (산업안전보건위원회 등으로 갈음 가능) | 반기 1회 이상 점검 |
| 8 | 비상 대응 매뉴얼 | 중대산업재해 발생(우려) 시 작업중지·대피·구호·추가피해 방지 매뉴얼 | 반기 1회 이상 점검 |
| 9 | 도급·용역·위탁 관리 | 협력업체 선정 시 안전보건 역량 평가 기준·절차 마련 | 반기 1회 이상 점검 |

추가로 시행령 제5조: 안전보건 관계 법령 의무 이행 여부를 **반기 1회 이상 점검**, 필요한 교육 실시 여부 점검 등.

**처벌** (제6조·제7조·제15조)
- 사망: 경영책임자 1년 이상 징역 또는 10억 원 이하 벌금 / 법인 50억 원 이하 벌금
- 부상·질병: 7년 이하 징역 또는 1억 원 이하 벌금 / 법인 10억 원 이하 벌금
- 손해액의 5배 이내 징벌적 손해배상

## 3. 핵심 기능 (MVP — 5개)

### F1. 법 적용 자가진단
- **목적**: 1분 안에 두 법의 적용 여부와 해야 할 일 우선순위 확인
- **흐름**: 홈 → "자가진단 시작" → 질문 4~5개(상시 근로자 수, 업종, 건설업이면 공사금액, 도급·협력업체 유무, 유해물질 취급 여부) → 결과 카드 (중처법 적용 O/X, 산안법 주요 의무, 안전보건관리담당자 선임 대상 가능성) → "체크리스트로 이동" 버튼
- **저장**: 답변과 결과를 사업장 프로필로 저장 → 다른 기능의 기본값으로 사용(예: 전담 조직 항목 '해당 없음' 자동 표시)

### F2. 중처법 안전보건관리체계 이행 체크리스트
- **목적**: 9개 항목 + 시행령 제5조 점검 항목의 진척률 관리
- **흐름**: 체크리스트 탭 → 항목 카드 목록(상단에 전체 진척률 바) → 카드 탭 → 상태 선택(미착수 / 진행 중 / 완료 / 해당 없음) + 메모(증빙 위치·담당자) + 최근 점검일 입력 → 반기 점검 대상 항목은 "다음 점검 예정일" 자동 계산, 지난 경우 경고 배지
- **진척률**: 완료 수 ÷ (전체 − 해당 없음)

### F3. 간이 위험성평가
- **목적**: 빈도×강도 방식으로 위험요인 → 위험성 → 감소대책을 표로 남김
- **흐름**: 위험성평가 탭 → "평가 추가"(작업/공정 이름, 평가일) → 위험요인 행 추가(유해·위험요인 설명, 재해 형태 선택: 추락·끼임·부딪힘·넘어짐·화재·감전 등) → 가능성(빈도) 1~3, 중대성(강도) 1~3 선택 → 위험성 점수 자동 계산·색 구분(낮음/보통/높음) → 감소대책, 담당자, 완료 예정일 입력 → 대책 완료 후 개선 후 위험성 재입력
- **척도**: 3×3 기본(초보자 친화). 5×4 등은 나중에 (11절 질문)
- **도움말**: 재해 형태별 흔한 위험요인 예시 문구 제공(참고용)

### F4. 일일 TBM / 안전점검 기록
- **목적**: 매일 작업 전 회의·점검을 30초 안에 기록
- **흐름**: 기록 탭 → "오늘 기록" → 날짜(오늘 기본) · 작업 내용 · 오늘의 위험요인(F3 평가에서 불러오기 가능) · 안전대책 · 참석 인원 수 또는 이름 · 점검 항목 체크(보호구 착용, 정리정돈 등 기본 6~8개, 사용자 편집 가능) · 특이사항 → 저장 → 달력/목록에서 날짜별 확인
- **참고**: 서명 기능은 MVP 제외. 참석자 이름은 선택 입력(개인정보 최소화)

### F5. 기록 내보내기 (이행 증빙)
- **목적**: 사고·감독·외부 점검 시 보여줄 문서 만들기
- **흐름**: 설정/내보내기 탭 → 대상 선택(체크리스트 / 위험성평가 / TBM 기록, 기간) → "인쇄(PDF로 저장)" 또는 "CSV 다운로드" → 별도로 "전체 백업(JSON) 내보내기 / 가져오기"
- **인쇄**: 인쇄용 CSS(`@media print`)로 표 형태 문서, 상단에 사업장명·출력일, 하단에 면책 문구
- **CSV**: UTF-8 BOM 포함(엑셀 한글 깨짐 방지)

### 나중에 할 것 (MVP 제외)
- 안전보건교육 실시 기록·교육 시간 계산
- 비상 대응 매뉴얼 템플릿 작성기
- 협력업체(도급) 안전보건 평가표
- 체크리스트법·3단계 판단법 등 다른 위험성평가 방식
- 아차사고(니어미스) 신고·사진 첨부
- 반기 점검 알림(Notification API / PWA)
- PWA 오프라인 설치, 여러 사업장 프로필
- 근로자 서명(캔버스), QR 기반 TBM 참석 체크
- 법령 개정 소식 링크 모음

## 4. 화면 구성

### 4-1. 화면 목록

| ID | 화면 | 해시 경로 |

### 4-2. 내비게이션 (모바일 기준)
- **하단 탭 바 5개**: 홈 · 체크리스트 · 위험성평가 · 기록 · 더보기 (아이콘 + 글자, 각 탭 최소 44×44px, `safe-area-inset-bottom` 반영)
- 자가진단은 홈 카드와 더보기에서 진입
- 넓은 화면(`min-width: 768px`): 하단 탭 → 왼쪽 세로 내비게이션 또는 상단 탭으로 전환
- 상세 화면에는 상단 "← 뒤로" 버튼

## 5. 데이터 모델 (localStorage)

- 모든 키는 `sz:` 접두사(블로그 키와 충돌 방지). 각 값에 `schemaVersion` 포함 → 추후 마이그레이션.
- `localStorage` 접근은 전부 `try/catch`. 실패 시 "저장되지 않음" 안내 배너 표시(메모리 모드로 동작).
- 날짜는 `YYYY-MM-DD` 문자열, 시각은 ISO 8601.
- 용량 한계(약 5MB)를 고려해 사진 등 바이너리는 MVP에서 저장하지 않음.

| 키 | 내용 |
|---|---|
| `sz:meta` | 스키마 버전, 면책 고지 동의 시각 |
| `sz:profile` | 사업장 프로필·자가진단 결과 |
| `sz:duties` | 체크리스트 항목별 상태 |
| `sz:risks` | 위험성평가 목록 |
| `sz:logs` | TBM/점검 기록 목록 |
| `sz:settings` | 테마, 점검 항목 템플릿 |

## 7. 디자인 방향

### 색상 (안전 테마)
블로그(`css/style.css`)의 변수 이름·톤(밝은 회백색 배경, 차분한 회색 텍스트, 8px 라운드)을 따르되, 강조색만 안전 테마로.

| 변수 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| `--bg` | `#fcfcfb` | `#17191d` | 배경 (블로그와 동일) |
| `--surface` | `#f4f4f1` | `#1f2228` | 카드 |
| `--text` | `#1d2125` | `#e3e5e9` | 본문 |
| `--text-muted` | `#5a616b` | `#9aa1ac` | 보조 글자 |
| `--border` | `#e3e3df` | `#2e323a` | 테두리 |
| `--accent` | 안전 녹색 계열(예: `#1f7a4d`) | 밝은 녹색(예: `#5fd39a`) | 주요 버튼·진척률 |
| `--warn` | 안전 황색 계열(예: `#8a5a00` 글자 / `#ffd54a` 배경) | 조정 | 점검 기한 경고, 위험성 '보통' |
| `--danger` | 적색 계열(예: `#c62828`) | `#ff8a80` | 위험성 '높음', 기한 초과 |
| `--ok` | `--accent`와 동일 | — | 위험성 '낮음', 완료 |

- 색은 모두 `:root` 변수로 정의, `[data-theme="dark"]`에서 재정의. 컴포넌트에 색 값 직접 금지.
- 예시 색상값은 구현 시 대비 검사 후 확정(노란색 위 흰 글자 금지).
- 위험도는 **색 + 글자(낮음/보통/높음) + 아이콘** 함께 표시(색맹 대응).

### 다크 모드
- 기본은 `prefers-color-scheme`, 수동 토글은 `sz:settings.theme`에 저장.
- `<html data-theme>`로 적용, `<head>` 인라인 스크립트로 깜빡임 방지.
- 순수 검정 대신 `#17191d` 계열.

### 타이포그래피·레이아웃
- 폰트: `"Pretendard", -apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif` (블로그와 동일), `word-break: keep-all`.
- 본문 1rem~1.0625rem, 숫자(진척률·점수)는 크고 굵게.
- 모바일 우선, 좌우 여백 16px 이상, 가로 스크롤 금지. 표는 자체 `overflow-x: auto`, 모바일에서는 카드형 전환.

### 접근성
- 터치 대상 최소 **44×44px** (탭 바, 빈도/강도 선택 버튼, 체크박스 라벨 영역 포함)
- 본문 대비 **4.5:1 이상**, 큰 글자·아이콘 3:1 이상
- `:focus-visible` 포커스 링, 폼 요소마다 `<label>`, 진척률 바에 `role="progressbar"` + `aria-valuenow`
- 시맨틱 태그(`header`, `nav`, `main`, `section`, `time`), 화면 전환 시 제목으로 포커스 이동
- `prefers-reduced-motion` 존중(전환 효과 끔)
