오늘은 클로드 코드와 함께 이 블로그를 처음부터 만들었습니다. 프레임워크 없이 **HTML, CSS, JavaScript** 세 가지만으로 만들다 보니, 각자 맡은 역할이 또렷하게 보였습니다.

한 문장으로 줄이면 이렇습니다.

> HTML은 **뼈대**, CSS는 **옷**, JavaScript는 **움직임**이다.

## HTML: 뼈대

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 문단, 링크, 버튼 같은 내용과 구조를 담당합니다.

- `index.html`에 헤더, 본문 영역, 푸터의 자리를 만들었습니다.
- `header`, `main`, `article`, `time`처럼 의미가 담긴 태그를 쓰면 화면 낭독기나 검색 엔진도 페이지 구조를 이해할 수 있습니다.
- `<meta name="viewport">` 한 줄이 있어야 휴대폰에서 화면이 제 크기로 보입니다.

```html
<header class="site-header">
  <a class="site-title" href="#/">나의 블로그</a>
  <button id="theme-toggle" type="button">테마 전환</button>
</header>
<main id="app"></main>
```

## CSS: 옷

CSS는 그 내용이 **어떻게 보일지**를 정합니다. 색, 글꼴, 간격, 배치를 담당합니다.

- 색을 **CSS 변수**로 한곳에 모아 두니, 다크 모드는 변수 값만 바꾸면 끝났습니다.
- 본문 폭을 약 720px로 제한하고 줄 간격을 넉넉하게 두면 글이 훨씬 읽기 편해집니다.
- 작은 화면 기준으로 먼저 만들고, 화면이 넓어질 때만 스타일을 더하는 방식(모바일 우선)을 배웠습니다.

```css
:root {
  --bg: #fdfdfc;
  --text: #1f2328;
}

[data-theme="dark"] {
  --bg: #16181c;
  --text: #e4e6ea;
}
```

## JavaScript: 움직임

JavaScript는 페이지가 **어떻게 반응할지**를 정합니다. 데이터를 불러오고, 사용자의 행동에 따라 화면을 바꿉니다.

1. `fetch()`로 `posts/` 폴더의 마크다운 파일을 읽어 옵니다.
2. 직접 만든 변환기가 마크다운을 HTML로 바꿉니다.
3. 주소의 `#` 뒷부분이 바뀌면 그에 맞는 화면(목록, 글, 태그)을 그립니다.
4. 다크 모드 버튼을 누르면 테마를 바꾸고, 선택을 브라우저에 저장합니다.

```js
button.addEventListener('click', () => {
  const next = root.dataset.theme === 'dark' ? 'light' : 'dark';
  root.dataset.theme = next;
});
```

## 셋이 함께 일하는 방식

| 역할 | 담당 | 이 블로그에서의 예 |
| :--- | :--- | :--- |
| HTML | 구조와 내용 | 헤더, 본문 영역, 버튼 |
| CSS | 모양과 배치 | 색상 변수, 다크 모드, 모바일 레이아웃 |
| JavaScript | 동작과 데이터 | 글 불러오기, 화면 전환, 테마 저장 |

세 가지를 파일로 나눠 두면 고칠 곳을 찾기 쉽습니다. 색을 바꾸고 싶으면 CSS만, 새 기능을 넣고 싶으면 JavaScript만 보면 됩니다.

## 그 밖에 알게 된 것

- 파일을 더블클릭해서 열면 `fetch()`가 막히기 때문에, `python -m http.server` 같은 **로컬 서버**로 열어야 합니다.
- 글에 쓴 HTML 태그를 그대로 실행하면 위험할 수 있어서, 화면에 넣기 전에 특수문자를 안전한 글자로 바꾸는 과정이 필요합니다.
