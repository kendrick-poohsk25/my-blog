마크다운 파일 하나만 쓰면 바로 글이 되는 블로그를 만들었습니다. 프레임워크도, 빌드 과정도 없이 **HTML, CSS, JavaScript**만으로 동작합니다.

## 새 글 쓰는 방법

1. `posts/` 폴더에 새 `.md` 파일을 만듭니다.
2. 파일 맨 위에 글 정보를 적습니다.
3. `posts/index.json`에 파일을 등록합니다.

글 정보는 이렇게 적습니다.

```markdown
---
title: 글 제목
date: 2026-11-09
tags: 태그1, 태그2
description: 목록에 보일 짧은 요약
---
```

그리고 `index.json`에는 한 줄을 추가합니다.

```json
{ "slug": "my-new-post", "file": "my-new-post.md" }
```

> `slug`는 주소에 쓰이는 이름입니다. 영어 소문자와 하이픈(`-`)으로 짓는 것을 추천해요.

## 앞으로

천천히, 꾸준히 기록해 보려고 합니다.
