이 블로그에서 다크 모드를 켜고 새로고침해도 다크 모드가 그대로 유지됩니다. 처음에는 당연하게 여겼는데, 알고 보니 브라우저의 **localStorage**에 선택을 적어 두었기 때문이었습니다.

오늘은 이 localStorage가 무엇이고, 이 블로그에서 어떻게 쓰이는지 정리해 보겠습니다.

## localStorage는 브라우저 안의 작은 메모장

localStorage는 웹사이트가 브라우저에 **키와 값** 한 쌍을 저장해 두는 공간입니다. 탭을 닫거나 컴퓨터를 껐다 켜도, 사용자가 직접 지우기 전까지 남아 있습니다.

```js
localStorage.setItem('theme', 'dark'); // 저장
localStorage.getItem('theme');         // 'dark'
localStorage.removeItem('theme');      // 삭제
```

알아 두면 좋은 특징은 이렇습니다.

| 특징 | 설명 |
| :--- | :--- |
| 값의 형태 | 문자열만 저장됩니다. 숫자 `1`을 넣으면 `'1'`로 돌아옵니다. |
| 없는 키 | `getItem`이 `null`을 돌려줍니다. |
| 범위 | 사이트(출처)마다 따로 저장됩니다. `localhost:8000`과 `localhost:3000`도 서로 다른 공간입니다. |
| 비슷한 친구 | `sessionStorage`는 사용법이 같지만 탭을 닫으면 사라집니다. |

객체를 저장하고 싶다면 `JSON.stringify`로 문자열로 바꿔 넣고, 꺼낼 때 `JSON.parse`로 되돌리면 됩니다.

## 이 블로그에서는 try/catch로 감쌌다

`js/theme.js`를 보면 localStorage를 읽는 코드를 `try/catch`로 감싸 두었습니다.

```js
function readStored() {
  try {
    return localStorage.getItem(STORAGE_KEY);
  } catch {
    return null;
  }
}
```

브라우저 설정에서 사이트 데이터 저장을 막아 두었거나 일부 시크릿 모드처럼 저장소를 쓸 수 없는 환경에서는 localStorage에 접근하는 순간 오류가 날 수 있습니다. 그냥 두면 스크립트 전체가 멈추지만, 이렇게 감싸 두면 저장만 못 할 뿐 다크 모드 전환은 그대로 동작합니다.

## 페이지가 그려지기 전에 먼저 읽기

저장된 테마를 `js/theme.js`에서만 읽으면, 화면이 잠깐 밝게 보였다가 어두워지는 깜빡임이 생깁니다. 그래서 `index.html`의 `head` 안에 짧은 스크립트를 직접 넣어, CSS가 적용되기 전에 테마부터 정합니다.

```js
try { theme = localStorage.getItem('theme'); } catch (e) { theme = null; }
if (theme !== 'light' && theme !== 'dark') {
  theme = window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}
```

저장된 값이 `'light'`나 `'dark'`가 아니면 무시하고 OS 설정을 따르게 한 점도 눈여겨볼 만합니다. 저장소의 값은 사용자가 개발자 도구에서 마음대로 바꿀 수도 있으니, 꺼낸 값은 한 번 확인하고 쓰는 습관이 좋습니다.

## 마무리

localStorage는 몇 줄만으로 "사용자의 선택을 기억하는" 기능을 만들 수 있어 편리합니다. 다만 문자열만 저장된다는 점, 접근이 실패할 수 있다는 점, 비밀번호 같은 민감한 정보는 넣으면 안 된다는 점을 기억해 두려고 합니다. 개발자 도구의 Application(또는 저장소) 탭에서 `theme` 값이 바뀌는 모습을 직접 확인해 보는 것도 추천합니다.
